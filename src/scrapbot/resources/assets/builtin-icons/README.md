# Built-in icon sources

These regular-weight SVGs are a curated subset of
[Phosphor Icons](https://github.com/phosphor-icons/core), used under the
adjacent MIT license. Scrapbot compiles them through the same MTSDF pipeline
as project-authored icon sets.

Run `mise builtin-icons` after changing this catalog. `mise test` regenerates
the products in a temporary directory and rejects stale checked-in atlas or
symbol metadata.
